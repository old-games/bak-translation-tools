# Русские шрифты Betrayal at Krondor

Латиница осталась на своих местах (как в английской игре), кириллица — на кодах
0x80 и выше (`src/baktt/encoding.py`):

| Символы | Коды |
|---|---|
| А–Я | 0x80–0x9F |
| а–я | 0xA0–0xBF |
| Ё | 0xC0 |
| ё | 0xC1 |
| — (длинное тире) | 0xC2 |

Эти файлы основные: старые шрифты с доски Trello (кириллица поверх латиницы)
не использовать. Редактировать редактором шрифтов (`baktt gui font-editor` или
`baktt-font-editor.exe` из GitHub Actions): он подписывает символы русскими
буквами. `baktt patch-game` кладёт шрифты в игру и меряет ими ширину подписей
кнопок и тем разговора (`GAME.FNT`).

| Файл | Где используется |
|---|---|
| `GAME.FNT` | интерфейс и диалоги |
| `BOOK.FNT` | книги |
| `PUZZLE.FNT` | экран кодовых замков на сундуках |
| `ALIEN.FNT` | моррельские руны: надписи на моррельских сундуках, пока в отряде нет Гората |

## ALIEN.FNT

Руны стоят только на местах букв: в английском шрифте — на A–Z (у a–z те же).
Рунный текст — шифр замены, поэтому у каждой русской буквы своя руна
(временный вариант до рисунков художников, сделан `work/alien_runes.py`):

- на 0x80–0xC1 — руны латинских букв по созвучию (А — A, Б — B, В — V, Г — G…);
- 7 букв без пары (Ж, Ч, Щ, Ъ, Ь, Э, Я) — зеркальные руны (Z, C, F, B, P, E, R);
- Ё — руна Е, заглавные и строчные — одна руна, «—» — как дефис.

## Что нарисовано автоматически и требует проверки художником

- длинное тире «—» (0xC2) в GAME, BOOK и PUZZLE — сделано из дефиса;
- `GAME.FNT`: «ё» сделана из «е» (две точки), «Ё» пока просто копия «Е»;
- `PUZZLE.FNT`: строчная «з» сломана (не хватает 4 строк в высоту) — перерисовать;
- `ALIEN.FNT`: русские руны — временные, см. выше.
