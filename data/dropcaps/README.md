# Русские буквицы книг

Первый абзац каждой книги начинается с буквицы — картинки из `BOOK.BMX`. Сборка
(`patch-game`, `build-from-sp`, `src/baktt/dropcaps.py`) берёт первую букву
переведённого абзаца (`Cxx.BOK:000`), ставит её буквицу и убирает эту букву из
текста: переводчики пишут текст целиком, как обычно.

- Картинка буквы — `<буква>.png` в этой папке: `Д.png`, `П.png`, `Ш.png`…
  Перерисовать — заменить файл с тем же именем.
- Нет своей картинки — берётся оригинальная того же вида: В = B, О = O, А = A,
  Т = T, Р = P. Свой `В.png` заменяет латинскую B.
- Нет никакой — ошибка в отчёте сборки, абзац остаётся английским с английской буквицей.

Картинка: 16 цветов палитры `BOOK.PAL`, цвет 0 — прозрачный (фон страницы);
PNG индексированный с этой палитрой (как образцы) или RGB — цвета приводятся к
ближайшим. Размер любой, у оригиналов 48–96 × 68–100 px; ширина добивается
прозрачным справа до кратной 8. Образцы — оригинальные буквицы,
`bak/translation/dropcaps_samples/` (вне репозитория).

Текст обтекает прямоугольник (x1, y1, x2, y2 от угла страницы), у каждой книги
свой; при другом размере картинки x2 и y2 сдвигаются на разницу размеров.
Если ляжет плохо — задать вручную в `boxes.csv`:

```
book,x1,y1,x2,y2
C21.BOK,,,130,
```

(пусто = автоматически). Что получилось — раздел «Буквицы» в отчёте сборки;
превью страниц — `bak/work/book_preview.py`.
